# AI Mock Interview Platform

AI-powered interview preparation platform built using MERN Stack and OpenRouter AI.

## Features

- AI Technical Interviews
- Voice HR Interviews
- Resume Analyzer
- Coding Round
- Interview History
- Analytics Dashboard
- User Profile

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- OpenRouter AI
